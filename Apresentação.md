# Atividades e projetos em Python

Repositório com atividades e pequenos projetos que desenvolvo
para praticar programação em Python.

## Projetos

- Calculadora
- Simulação de empréstimo bancário
- Estacionamento inteligente
- Matrícula em curso
- Pizzaria

## Como executar

É necessário ter o Python instalado.

Abra a pasta do projeto no VS Code e execute o arquivo Python
correspondente.
