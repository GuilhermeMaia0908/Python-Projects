# Calculadora em Python

Calculadora simples que desenvolvi para praticar os conceitos básicos de Python.

## Funcionalidades

A calculadora realiza as seguintes operações:

- Adição (+)
- Subtração (-)
- Multiplicação (*)
- Divisão (/)
- Potenciação (**)
- Resto da divisão (%)

Os resultados são exibidos com duas casas decimais.

## Como executar

1. Tenha o Python 3 instalado.
2. Baixe o arquivo `calculadora.py`.
3. Abra o terminal na pasta onde o arquivo foi salvo.
4. Execute:

```bash
python calculadora.py
```

5. Escolha uma operação e digite os dois números solicitados.

Para números decimais, utilize ponto, como `2.5`.

## Exemplo de uso

```text
Digite a operação (+, -, *, /, **, %): +
Digite o primeiro número: 10
Digite o segundo número: 5
O resultado da soma será: 15.00
```

## Conceitos praticados

- Entrada de dados com `input()`
- Conversão de valores com `float()`
- Condicionais: `if`, `elif` e `else`
- Operadores matemáticos
- Formatação de números com `.format()`
